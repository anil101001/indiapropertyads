Land/Plots Category – Filter Structure (Word Document Version)OverviewWhen a user selects “Land/Plots,” the system should automatically load only relevant filters while hiding irrelevant ones like bedrooms or bathrooms.Core Filters (Mandatory)These are essential for any land/plot search.• Property Type (Pre-selected as Land/Plot; sub-options):  - Residential Plot  - Commercial Plot  - Industrial Plot  - Agricultural Land  - SEZ Plot  - Mixed-Use Land• Land Area (Size): Numeric range with unit selector:  - Square Meters (sq. m)  - Square Feet (sq. ft)  - Yards  - Acres  - Hectares• Location:  - City, State, Pin Code, Locality, or Interactive Map Search• Price:  - Min/Max RangeSpecific Land/Plot Filters (Optional / Advanced)These provide specialized insights crucial for developers and investors.• Zoning Classification (multi-select):  - Approved for Residential  - Approved for Commercial  - Approved for Industrial  - Agricultural (with regulatory notes)  - IT/SEZ  - Mixed-Use Approved  (Defines what can be legally built)• Layout Status:  - Approved Layout (Municipal / RERA)  - Unapproved Layout  - Gated Community Plot• Ownership Type:  - Freehold  - Leasehold• Legal / Clearance Status:  - Clear Title  - Litigated  - RERA Approved• Amenities / Features (optional):  - Boundary Wall / Fencing  - Road Access (Highway facing, 4-lane road, etc.)  - Water Connection Availability  - Electricity Connection Availability  - Proximity to Transport Hubs or Major InfrastructureConclusionBy implementing these filters, the platform provides a refined, efficient, and globally aligned search experience for users exploring land and plot investments.
